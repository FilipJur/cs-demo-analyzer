### MAP-ANC-011 — Chokes

A Main (narrow, single-molly); Donut entrance; Cave (long committing corridor); B Ramp; Connector. CTs rush

### MAP-ANC-012 — Elevation / cover

Heaven/Catwalk, Red, Nest AWP perch, Window, Boost, Plat/BigBox, Pillar/Square, Temple raised default + bridge;
Xbox unexpected elevations; Pit recessed Elbow surprise but molly-vulnerable; Triple covers Main + Donut; Pillar
changes angle — CS2Hype (Temple Wrap / Donut One-Way / Cave Headshot / B-Alley Deep).

### MAP-ANC-013 — Deciding connections

Donut cuts Mid↔A; Cave links centre↔B without the bomb; RedRoom regroups; CT-Spawn is smoke-isolatable; BackHalls
retakes — CounterStrikeHub + CS2Hype. Favors patient CTs: Cave forces commitment, Donut rotation risk, A Main a
death trap without utility.

### MAP-ANC-014 — Visibility

Verified one-ways: A-Main foot-gap + Donut/CT-mid + over-wall Donut flashes — CS2Hype. **Temple→Main deletion
removes a real ray** (post-14-Aug-2025). Doors named only; operability unverified. Foliage/wetness-moss
readability unquantified. Duplicate Short needs zone-disambiguation.

### Core thesis, Ancient flavor

Proximity (Cave↔B, Donut↔either site) ≠ support; unobstructed ray (foliage, smoke edges — or the now-walled
Temple→Main) ≠ availability. Availability = staged utility × fixing × route distance × economy-gated roles ×
info × setup priors × clearing order × buy state × role assignment.

## 5. Role-dependent responsibilities

All valid only given timing, economy, alive, pressure, info, objective; no fixed spots.

- **Donut / CT-mid:** contest/deny/relay/rotate while info flows.
- **A pair:** post-patch re-split Main without the Temple ray (**exact split unverified**); early Main call,
  delay molly, survive for Donut/ramp help while Main info fresh. Temple Wrap pre-patch suspect. Far-pillar
  off-angle the leading post-patch candidate — unverified — CS2Hype.
- **B pair/solo:** Alley passive + spawn ramp-watch; footstep listening (Cave amplifies crouch/walk/run);
  molly on contact; pre-agreed mid-man threshold while Cave sound monitored; solo never dies free.
- **Mid pair (T):** entry + wider trade + late utility; never triple-stacked — EdgeSkins. Donut wide-peek uses
  peeker's advantage as pre-commit info.
- **Extremity / lurk:** hold the re-take lane, punish greedy swings only with fixing + known bomb. Donut flanks
  A / cuts rotates; Cave pressures B without bomb. Mid-Donut late lurk: quiet pre-1:30 Donut, hold exit,
  Connector flank or CT-Spawn→B.
- **AWPs:** T mid post-utility + economy read; CT Cave-elevation/Heaven/Nest early without becoming predictable
  (Cave Headshot ideal AWP early). Less AWP-dominated overall; corridors favor rifles/lurkers.

## 7. Common questionable decisions and legitimate exceptions

- **Dry-swing Donut/elbow after pause → delayed-flash death.** *Exception:* paired relay + support flash +
  pre-called give-ground — EdgeSkins.
- **Dry-peek narrow Main / solo-enter Cave flashing nothing** ("never commit Cave without smoke — mandatory
  even pistols"; "dry Cave / rushing smokes / ignoring Mid" canonical) — CS2Hype + Hard2Kill.
  *Exception:* traded pair + pre-utility.
- **Clump mid** (stall/spam/body-block). *Exception:* deliberate bait-stack with spacing-behind + flank-watch.
- **Instant noise-rotation** (Cave-fake "pull rotator then switch" punishes; "rotate only on confirmation").
  *Exception:* bomb located or multi-smoke commitment — EdgeSkins + CS2Hype.
- **Admiring won space / unfixed lurk.** *Exception:* conditioning pauses forcing spend; deliberate Mid-Donut
  late-lurk form — EdgeSkins + CS2Hype.
- **Post-patch Temple→Main anchor categorically wrong** — flag post-14-Aug-2025. Pre-May-2026 boosts re-verify
  (2026-05-28 clipping).
- **Setup errors:** solo-A superhero vs chained utility; zero-mid; five-man-mid; 4-stacks outside hard-reads;
  planter-safe but post-plant-indefensible — EdgeSkins + CS2Hype mistakes.
- **Economy shapes** (Caller playbook indexes, plans not proof): T half-buy 5 calls (Mid-info / Mid-control
  flash+Elbow molly / B Short-smoke / A Temple+Donut / Cave-only gamble); CT half-buy 4 (delay-Mid / aggro-Mid /
  3B-stack / Cave-push); T pistol 4 (5-Mid→Donut→A / B-Cave flood / A-Main burst / Mid-split-B); CT pistol 4;
  T eco 4 all-in bodies; CT eco 4 stacks — [cs2caller](https://cs2caller.com/ancient/t/half-buy) + siblings.
